TimeFrequencyAnalysis

Time-frequency analysis of uniformly sampled signals.

The package provides container types for signals and their spectral representations (signal, framed_signal, spectrum, timefreq, modfreq), routines to split signals into frames, and spectral / spectro-temporal analyses (dft, magspec, specgram, welch_psd, periodogram), together with supporting utilities (window functions, frequency grids, resampling and synthetic signal generators). Correlation analyses (xcorr, acorr, acf, nacf) and digital filter responses on arbitrary frequency grids (filter_coefs, filter_resp, filter_magresp) complete the classical toolkit. An auditory-model branch adds the complex gammatone filterbank of Hohmann (2002): ERB-scale frequency grids (erbfreq_array), filter and filterbank design (gammatone_filter, gammatone_filterbank), complex-subband and cochleagram analyses (gammatone_analysis, gammatone_cochleagram), and per-channel delay and phase alignment (gammatone_delay, default_align, compensate). On top of that branch sits modulation analysis — how the energy in each channel fluctuates over time rather than how it is spread across frequency at one instant: power_envelope for the decimated subband envelopes and modulation_spectrum for their joint carrier-by-modulation-rate spectrum. Plot recipes for the container types load automatically when the Plots ecosystem (RecipesBase) is present — a package extension, so none of it is a hard dependency.

All types are parametric in the floating point precision T<:AbstractFloat of the signal, and every routine computes in that precision: a Float32 signal produces Float32 results throughout with no intermediate promotion to Float64.

Most analyses come in two flavours, selected by dispatch: called normally they return a spectrum/timefreq/modfreq container carrying the frequency and time indices (and, where it is meaningful, the signal itself); called with comp() as the first argument they return the plain component array only.

source

The package grew out of SpeechBox.jl, which now builds its speech analyses on top of it and re-exports this package's API.

Design in one paragraph

A signal lives in a signal container (samples plus sampling rate). A framed_signal adds a framing geometry without copying anything. Analyses return their results in spectrum (frequency axis) or timefreq (time and frequency axes) containers that keep the provenance of the result — or, when called with comp() as the first argument, return the plain component array only. All containers are parametric in the floating point precision of the signal, and every routine computes in that precision, so Float32 in means Float32 out.

Quickstart

using TimeFrequencyAnalysis

fs = 8000.0
x  = cos.(2π*440 .* (1:8000) ./ fs) .+ 0.1 .* white_noise(8000)

s      = signal(x, fs)               #signal container
frames = framed_signal(s, 0.02, 0.01)  #20 ms frames every 10 ms

spec = magspec(s)                      #spectrum object
tf   = specgram(frames)                #timefreq object (STFT magnitude)
db   = amp2db(tf)                      #elementwise dB, still a timefreq

S    = specgram(comp(), frames)        #the same STFT as a plain Matrix
