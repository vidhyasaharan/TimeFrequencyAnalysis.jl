Utilities

Supporting functionality used throughout the package and useful on its own.

Window functions

TimeFrequencyAnalysis.window — Function
window(len [; wtype = "hanning"])
window(T, len [; wtype = "hanning"])

Generate a window vector of length len and type wtype, with element type T<:AbstractFloat (default Float64). An unrecognised wtype falls back to the Hann window with a warning.

Implemented window types (wtype)

  • "hanning" : Hann window [default]
  • "hamming" : Hamming window
  • "rect" : rectangular window

Frequency grids and indexing

Frequency grids define the analysis frequencies for periodogram and can be used to build custom analyses; frqindex maps frequencies back to grid indices.

TimeFrequencyAnalysis.logfreq_array — Function
logfreq_array(; fmin = 10, fmax = 4000, frq_per_octave = 120)

Generate an array of frequencies in Hz, equally spaced in the log domain between fmin and fmax, with a resolution of frq_per_octave frequencies per octave.

source
TimeFrequencyAnalysis.linfreq_array — Function
linfreq_array(; fmin = 0, fmax = 4000, nfrqs = 80)

Generate an array of nfrqs equally spaced frequencies in Hz between fmin and fmax (both included).

source
TimeFrequencyAnalysis.frqindex — Function
frqindex(f, frqs)

Index into the frequency grid frqs of the frequency closest to f. When f is a vector, a vector of indices is returned.

source

Sampling helpers

TimeFrequencyAnalysis.time2nsamples — Function
time2nsamples(dur, fs)

Number of samples spanned by a duration of dur seconds at sampling rate fs Hz, rounded to the nearest integer.

source
TimeFrequencyAnalysis.resample — Function
resample(s::signal, fs_new)

Resample the signal s to the new sampling rate fs_new and return the result as a new signal. Wraps the polyphase resample from DSP.jl.

Synthetic signal generators

Deterministically shaped random and periodic test signals, used by this package's test suite and convenient for experiments and examples.

TimeFrequencyAnalysis.white_noise — Function
white_noise([T,] len)
white_noise(dur, fs)

Generate len samples (or dur seconds at sampling rate fs) of unit-variance Gaussian white noise with element type T<:AbstractFloat (default Float64). Each call draws from a freshly seeded random number generator.

source
TimeFrequencyAnalysis.ar_process — Function
ar_process(a, len)
ar_process(a, dur, fs)

Generate len samples (or dur seconds at sampling rate fs) of an autoregressive process by filtering white noise with the all-pole filter 1/A(z) whose denominator coefficients are given by the vector a (ordered as [1, a₁, a₂, ...]).

source
TimeFrequencyAnalysis.impulse_train — Function
impulse_train([T,] period, len)
impulse_train(f₀, dur, fs)

Generate len samples of a unit impulse train with period samples between impulses (the first impulse is at sample 1), with element type T<:AbstractFloat (default Float64). Alternatively specify an impulse rate f₀ in Hz and a duration dur in seconds at sampling rate fs.

Padding

TimeFrequencyAnalysis.zero_pad — Function
zero_pad(x, pad_len)

Return a copy of vector x with pad_len zeros prepended and appended.

source
TimeFrequencyAnalysis.symmetric_pad — Function
symmetric_pad(x, pad_len)

Return a copy of vector x extended by pad_len samples at each end by mirroring the signal about its end points (the end points themselves are not repeated).

source
TimeFrequencyAnalysis.unpad_vector — Function
unpad_vector(x, pad_len)

Remove pad_len samples from each end of vector x, undoing zero_pad or symmetric_pad.
