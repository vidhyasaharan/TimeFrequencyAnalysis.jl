Internals

Notes for maintainers, plus docstrings of unexported helpers.

Precision parametrisation

Every container type is parametric in T<:AbstractFloat, the element type of the signal it was built from, and every routine allocates its buffers and outputs in T. The rules used throughout the source:

  • literal constants inside generic code are converted with T(...) so they do not promote Float32 computations to Float64;
  • outputs of Float64-only library calls (the DSP.jl window shapes, for example) are converted once per call with convert(Vector{T}, ...), which is free when T == Float64;
  • frequency grids (logfreq_array, linfreq_array) are always generated in Float64; the container constructors convert them to T on storage.

Constructor funnelling

spectrum and timefreq have one central converting constructor that all convenience constructors call; it converts every field to the signal's precision and then invokes the default (implicit) constructor. When adding constructors, funnel through it rather than calling the default constructor directly.

TimeFrequencyAnalysis.H — Function
H(F, z)
H(F, f, fs)

Evaluate the rational transfer function described by F::filter_coefs at the complex point z, or at analogue frequency f in Hz given sampling rate fs (i.e. at $z = e^{i2πf/f_s}$). The numerator and denominator polynomials are evaluated in negative powers of z — the standard $z^{-1}$ convention — so phase responses and group delays carry their usual signs (a pure delay $z^{-1}$ has phase $-θ$).

source
TimeFrequencyAnalysis.Hmag — Function
Hmag(F, θ)
Hmag(F, f, fs)

Magnitude of the transfer function described by F::filter_coefs at digital angular frequency θ in radians per sample, or at analogue frequency f in Hz given sampling rate fs. Equivalent to abs(H(F, exp(im*θ))).

Gammatone design helpers

TimeFrequencyAnalysis.check_gammatone_args — Function
check_gammatone_args(fs, fc, order)

Validate gammatone design parameters and return (fs, fc) converted to Float64, the design arithmetic precision. Errors for out-of-range values; warns when fc > 0.45fs, where the one-sided design's neglect of the response wrap-around starts to bite.

source
TimeFrequencyAnalysis.a_gamma — Function
a_gamma(order)

Bandwidth factor $a_γ$ of Hohmann (2002) Eq. 14, relating the damping b of an order-th order gammatone filter to its equivalent rectangular bandwidth $a_γ b$. For the default order 4, $a_4 = 5π/16 ≈ 0.98175$.

source
TimeFrequencyAnalysis.default_ir_length — Function
default_ir_length(gf)

Number of samples after which the impulse-response envelope of gf has decayed to −80 dB relative to its peak: the default length used by gammatone_impulse_response. Found by walking the envelope ratio $|h[n+1]|/|h[n]| = λ(n+order)/(n+1)$ outwards from the envelope peak.
