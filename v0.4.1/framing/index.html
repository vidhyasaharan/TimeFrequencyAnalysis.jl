Framing

A framed_signal describes how a signal divides into (typically overlapping) frames; the functions on this page materialise those frames and compute frame-wise quantities.

  • view_frame — create a view of one frame
  • extract_frame — extract one frame as a new vector
  • enframe — store all frames of a signal as the columns of a matrix
  • number_signal_frames — number of frames that fit inside a signal
  • frame_energy — energy of each frame

view_frame

TimeFrequencyAnalysis.view_frame — Function
view_frame(x::framed_signal, i)

Create a view of frame number i of the framed_signal x. Frames that extend past the end of the signal (indices between num_signal_frames and num_frames) are returned as freshly allocated zero padded vectors instead of views.

enframe

TimeFrequencyAnalysis.enframe — Function
enframe(f::framed_signal)

Generate a matrix with each column storing one frame of the framed_signal f, i.e. materialise every frame that view_frame can produce. The matrix holds all f.num_frames frames, so the trailing ones that extend past the end of the signal are zero padded exactly as view_frame returns them.

source
enframe(x, frame_size, frame_shift)

Generate a matrix with each column storing one frame of length frame_size samples from the signal in array x, with consecutive frames separated by exactly frame_shift samples. Frames extending past the end of x are zero padded, as in view_frame.

source
enframe(x, fs, frame_dur, frame_shift_dur)

Generate a matrix with each column storing one frame of duration frame_dur seconds from the signal in array x with sampling rate fs, with consecutive frames separated by frame_shift_dur seconds. Frames extending past the end of x are zero padded, as in view_frame.

source
enframe(s::signal, frame_dur, frame_shift_dur)

Generate a matrix with each column storing one frame of duration frame_dur seconds from the signal s, with consecutive frames separated by frame_shift_dur seconds. Frames extending past the end of the signal are zero padded, as in view_frame.

source
TimeFrequencyAnalysis.enframe! — Function
enframe!(A, x)

Fill each column of matrix A with a frame of array x. The frame size is given by the number of rows of A and the frame shift is chosen so that the final frame ends as close as possible to the end of x.

frame_energy

TimeFrequencyAnalysis.frame_energy — Function
frame_energy(sig_frames::framed_signal[; normalised = false])

Estimate the energy of each frame of sig_frames as the sum of squares of its samples. With normalised = true the energies are scaled so that the maximum is 1. The result covers all num_frames frames (the trailing zero padded ones included).
